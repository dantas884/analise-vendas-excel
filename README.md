# 📊 Análise de Vendas com Excel

## 🎯 Objetivo
Este projeto tem como objetivo analisar dados de vendas e gerar insights estratégicos utilizando Excel, com foco em indicadores de desempenho e comportamento de clientes.

---

## 🛠️ Ferramentas Utilizadas
- Excel (Tabela Dinâmica, PROCV, KPIs)
- Manipulação de dados
- Análise exploratória

---

## 📂 Base de Dados
- Clientes
- Pedidos
- Produtos
- Itens de Pedido

---

## 📊 KPIs Criados
- 💰 Faturamento Total: R$ 4.048.695,22  
- 📦 Ticket Médio: R$ 4.048,70  
- 🏆 Top 5 Clientes: 6,42% do faturamento  
- 🔝 Top 10 Clientes: 11,54% do faturamento

## 🧠 Insights
Os 10 principais clientes representam apenas 11,54% da receita total, indicando baixa concentração e menor dependência de grandes clientes.
